Linux · X11 · C++20

外部只读的游戏状态叠加层

通过 /proc/<pid>/mem + pread64 读取游戏状态， 用无边框透明 Qt6 窗口绘制信息层，输入由 XTest 合成。 不注入进程，不写入游戏内存。

Qt6 Widgets · CMake ≥ 3.21 · 单文件可执行 · 仅支持 Linux

功能

全部开关与参数都在控制面板里调，改动 400 ms 内自动落盘生效。

信息叠加

  • 方框 · 血量条 · 血量/护甲数值 · 距离
  • 骨骼连线（头 → 颈 → 胸 → 骨盆）
  • 伤害浮字、残影轨迹、最低血量描边
  • 遮挡虚线（基于可见性标记）

2D 雷达

  • 可随视角旋转，也可固定北向
  • 三等分距离圈 + 米数刻度
  • 位置可选：底部居中 / 四角

屏外指示

  • 视野外敌人在屏幕边缘显示方位箭头
  • 箭头内侧标注距离米数
  • 相机后方目标取反映射，不会指反

敌人列表

  • 按距离排序，最多 10 行
  • 显示距离与血量，颜色区分敌我
  • 位置可选，适合远距离交战

高度差

  • 对比目标与自身的 z 轴差值
  • 超过 0.6 m 显示 ▲ / ▼ 与米数
  • 多层地图不用再靠方框位置猜楼层

输入辅助

  • 自瞄：FOV 过滤、平滑步数、灵敏度、目标策略、目标锁定
  • 后坐力抵消：按实测角度反向补偿，可限制仅开火时生效
  • 子弹追踪 / 静默锁头 / 自动扳机
  • 触发键支持键盘与鼠标，面板点一下即可录制

控制面板

  • 左侧分类列表，右侧参数就地展开
  • 自绘 iOS 形制开关，140 ms 缓动
  • 半透明玻璃底板，背景实时跟随
  • F8 显隐面板 · F9 一键静默

运行时

  • 采样与重绘解耦，互不阻塞
  • 配置与偏移文件改动自动重载，不必重启
  • 诊断日志超 2 MB 自动截断
  • 偏移失效时状态栏直接列出缺失字段

架构

五层单向依赖，渲染与输入都不直接碰内存读取。

ui 控制面板：配置编辑、热重载、日志
render 叠加层：ESP 绘制、雷达、屏外指示
features 输入合成：自瞄 / 追踪 / 静默 / 扳机 / 后坐力
game 实体分块遍历 → 纯数据快照
core 内存读取、投影数学、偏移与配置

共享状态只有一份 std::atomic<std::shared_ptr<Config>>， 读取方永远拿到不可变副本；采样结果以带锁快照交给渲染与输入线程。

快速开始

1

构建

sudo apt install qt6-base-dev libx11-dev libxext-dev libxtst-dev
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build -j"$(nproc)"
2

准备偏移

python3 tools/cs2_linux_offsets.py

游戏运行后执行，生成 config/offsets.json；程序启动时也会自动刷新一次。

3

运行

sudo ./build/cs2_lite

读取 /proc/<pid>/mem 需要 root，或先执行 sudo sysctl -w kernel.yama.ptrace_scope=0。

快捷键

F8 显隐控制面板  ·  F9 一键静默（隐藏叠加层并停止全部输入合成，再按恢复）

下载

发布包包含 cs2_lite 可执行文件与 default.json 默认配置。 把配置放到可执行文件同目录并改名为 config.json 即可。

说明

  • 本项目只读游戏内存，不注入进程、不修改内存、不伪造网络包。
  • 仅面向 Linux / X11，独占全屏无法叠加，请使用无边框窗口或全屏窗口模式。
  • 根据游戏版本自行生成偏移；版本更新后偏移失效属正常现象。
  • 仅供本地单机研究与技术学习，不提供任何形式的商业分发或售后。
