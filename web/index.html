Linux · X11 · C++20

外部游戏状态叠加与输入辅助

通过 /proc/<pid>/mem + pread64 采集游戏状态， 用无边框透明 Qt6 窗口绘制信息层，输入优先使用 UInput、失败时回退 XTest。 不注入进程；六组直接内存功能默认关闭，仅在显式开启后写入。

功能

全部开关与参数都在控制面板里调，改动 400 ms 内自动落盘生效。

信息叠加

  • 方框 · 血量条 · 血量/护甲数值 · 距离
  • 骨骼连线（头 → 颈 → 胸 → 骨盆）
  • 伤害浮字、残影轨迹、最低血量描边
  • 遮挡虚线（基于可见性标记）

2D 雷达

  • 可随视角旋转，也可固定北向
  • 三等分距离圈 + 米数刻度
  • 位置可选：底部居中 / 四角

屏外指示

  • 视野外敌人在屏幕边缘显示方位箭头
  • 箭头内侧标注距离米数
  • 相机后方目标取反映射，不会指反

敌人列表

  • 按距离排序，最多 10 行
  • 显示距离与血量，颜色区分敌我
  • 位置可选，适合远距离交战

高度差

  • 对比目标与自身的 z 轴差值
  • 超过 0.6 m 显示 ▲ / ▼ 与米数
  • 多层地图不用再靠方框位置猜楼层

输入辅助

  • 自瞄：FOV 过滤、平滑步数、灵敏度、目标策略、目标锁定
  • 后坐力抵消：按实测角度反向补偿，可限制仅开火时生效
  • 子弹追踪 / 静默锁头 / 自动扳机
  • 触发键支持键盘与鼠标，面板点一下即可录制

直接内存功能（默认关闭）

  • 加速 · 子弹追踪内存锁 · 飞天
  • 身体旋转 · 真无后坐力 · 弹着点控制
  • 需要可写 /proc 与当前版本偏移；关闭时尝试恢复原值
  • 字段写入不代表服务器认可，须离线验证效果

控制面板

  • 左侧分类列表，右侧参数就地展开
  • 自绘 iOS 形制开关，140 ms 缓动
  • 半透明深色双栏卡片布局，支持当前页搜索
  • F8 显隐面板 · F9 一键静默 · F10 清空本局统计

运行时

  • 采样与重绘解耦，互不阻塞
  • 配置与偏移文件改动自动重载，不必重启
  • 诊断日志超 2 MB 自动截断
  • 偏移失效时状态栏直接列出缺失字段

架构

五层单向依赖；输入通过共享快照选靶，MemoryEngine 独立执行显式开启的内存写入。

ui 控制面板：配置编辑、热重载、日志
render 叠加层：ESP 绘制、雷达、屏外指示
features 输入合成与 MemoryEngine：自瞄 / 扳机 / 六组直接内存功能
game 实体分块遍历 → 纯数据快照
core 内存读写、投影数学、偏移与配置

共享状态只有一份 std::atomic<std::shared_ptr<Config>>， 读取方永远拿到不可变副本；采样结果以带锁快照交给渲染与输入线程。

快速开始

1

构建

sudo apt install qt6-base-dev libx11-dev libxext-dev libxtst-dev
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build -j"$(nproc)"
2

准备偏移

python3 tools/cs2_linux_offsets.py

游戏运行后执行，生成 config/offsets.json；程序启动时也会自动刷新一次。

3

运行

sudo ./build/cs2_lite

同用户读取仍可能受 Yama 限制，可执行 sudo sysctl -w kernel.yama.ptrace_scope=0；直接内存写入还要求可写 mem fd 与 /dev/uinput 权限。

快捷键

F8 显隐控制面板  ·  F9 一键静默（停止输入并恢复内存字段） ·  F10 清空本局统计

下载

发布包包含 cs2_lite、默认配置与 config/offsets.json。 将默认配置复制为可执行文件旁的 config.json，保持 offsets 相对目录并从发布目录启动。

说明

  • 采集链路通过 /proc/<pid>/mem 读取；六组直接内存功能默认关闭，开启后会修改进程字段。不注入、不伪造网络包。
  • 仅面向 Linux / X11，独占全屏无法叠加，请使用无边框窗口或全屏窗口模式。
  • 根据游戏版本自行生成偏移；版本更新后偏移失效属正常现象。
